# Support

- **Questions and ideas:** [GitHub Discussions](https://github.com/hluxenhofer/checksum-verify/discussions)
- **Bugs:** [open an issue](https://github.com/hluxenhofer/checksum-verify/issues/new/choose) using the bug report form
- **Security vulnerabilities:** do not open a public issue; follow [SECURITY.md](SECURITY.md)

ChecksumVerify is maintained in spare time on a best-effort basis. Only the latest release is supported.
